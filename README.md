# Puzzle Heroes

Prototype Android puzzle-adventure game built with Godot 4.

## Step 1 — Level 1 prototype

- Portrait layout.
- 7 x 8 Match-3 board.
- Swipe to exchange adjacent tiles.
- Valid matches of 3+ tiles are cleared.
- Tiles collapse and refill.
- Score and move counter.
- Adventure area above the board.
- Placeholder hero/monster/obstacle visuals ready to be replaced by original art.

## Next step

Add real obstacle mechanics, character movement, animations, sound effects, and the first complete rescue objective.

## Android

The project is prepared for Godot Android export. Godot's official documentation recommends matching the installed export templates to the editor version; Google Play releases use signed AAB packages.
